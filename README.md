# Car Price Prediction

## Project Overview

This project predicts the selling price of a used car using Machine Learning.

The model is trained using a Random Forest Regressor and predicts the selling price based on various car features such as present price, kilometers driven, fuel type, seller type, transmission type, owner count, and car age.

## Features

- Data Preprocessing
- Feature Engineering (Car Age)
- Label Encoding
- Data Visualization
- Model Training
- Model Evaluation
- Streamlit Web Application

## Dataset Features

- Present Price
- Kms Driven
- Fuel Type
- Seller Type
- Transmission
- Owner
- Car Age

## Machine Learning Algorithm

- Random Forest Regressor
